機能一覧・スラッシュコマンド

ミア本体に実装されている全機能とスラッシュコマンドの詳細仕様一覧です。

TRPG ・ ダイス機能 BCDice連携

/dice ダイス総合コマンド

BCDiceと連携したダイスロール、出目統計の確認、サーバーごとの動作設定を行えます。

/dice use roll roll:式 [dicebot:システム] [hide:真偽値]
指定したダイスボットでシークレットロール(非公開ロール)または通常ロールを実行します。
/dice use statistics [type:形式] [user:対象] [hide:真偽値]
これまでのD100の出目統計データをグラフ・数値で表示します。
/dice settings system dicebot:システム [help-response:設定]
チャットで直接振る際のデフォルトダイスボットやヘルプ応答を設定します。
/dice settings blacklist channel:チャンネル type:追加/削除
チャットでのダイス自動反応を無効化するチャンネルを指定・解除します。
/trpg TRPG専用サポート

キャラクターシート作成時のダイス一括振りやココフォリアログの解析を行います。

/trpg chara-make type:システム [detail:詳細演算] [hide:真偽値]
クトゥルフ神話TRPGなどの能力値ダイスを一括で振り、SAN値やダメージボーナスまで自動計算します。
/trpg dicelog-statistics type:システム html:ログファイル [hide:真偽値]
ココフォリアの全チャットログHTMLファイルをアップロードすることで、セッション内のダイス出目統計を出力します。
チャットダイス直接入力 常時機能

コマンドを使わなくても、チャット欄にプレフィックス付きで入力するだけでダイスが振れます。

例: coc 1d100<=50 / coc7 cc<=60 / emo 2d6 / shinobi 2d6
対応プレフィックス: coc (クトゥルフ6版), coc7 (クトゥルフ7版), emo (エモクロア), shinobi (シノビガミ), futari (フタリソウサ), para (パラノイア), stell (ステラナイツ), bc (一般BCDice)

カラーユーティリティ 色彩ツール

/color カラー情報・変換

カラーコードの相互変換やランダムカラーの抽出を行います。

/color convert from_code colorcode:コード [hide:真偽値]
「#38bdf8」などのカラーコードからRGB・HEX値・カラープレビューを出力します。
/color convert from_hex hex:10進数HEX [hide:真偽値]
10進数のHEXカラー数値からカラーコード情報を変換出力します。
/color convert from_rgb red:赤(0-255) green:緑(0-255) blue:青(0-255)
RGBの各要素からカラーコードを生成します。
/color convert random [hide:真偽値]
ランダムに色を1色抽出し、各形式の値と色プレビューを表示します。
チャット内カラー自動可視化 常時機能

通常のチャット発言の中に「#ffffff」などの6桁カラーコードが含まれると、自動で該当する色の画像・情報をプレビュー表示します。

生活 ・ サーバーユーティリティ リマインダー・ID管理

/remind リマインダー

指定した時間に指定チャンネルへメンション付きのリマインドメッセージを投稿します。

/remind create time:時間 title:タイトル [at:投稿先] [note:メモ]
リマインドを作成します。「10m」「1h」「2026/10/10 15:00」等の形式で柔軟に時間を指定可能です。
/remind delete id:リマインド
登録したリマインドを一覧から選択して削除します。
/idcard IDカード管理

メンバー同士でSNSやゲームのフレンドIDを共有・確認できるIDカード機能です。

/idcard view [user:対象ユーザー] [hide:真偽値]
指定したユーザー(または自分)のIDカードを閲覧します。
/idcard set title:サービス名 value:ID
自分のIDカードにSNSやゲームIDを設定します。
/idcard edit title:項目名 value:ID
選択肢にないカスタム項目を新規作成・編集します。
/idcard remove title:項目名
IDカードから特定の項目を削除します。
/reply 自動キーワード返信

特定のワードにミアが自動でリアクション・返信するための設定です。

/reply add word:キーワード reply:返信内容 [hide:真偽値]
自動返信の対象ワードと返信内容を登録します。
/reply remove work:キーワード
登録済みのキーワード返信設定を削除します。
/message メッセージ管理

メッセージのメタデータ確認やチャンネルログの保存を行います。

/message info msg:メッセージID [channel:チャンネルID]
メッセージの詳細情報(送信時刻、ID、リンク等)を開示します。
/message save [format:形式]
コマンドを実行したチャンネルのチャットログを書き出し保存します。
/vc ボイスチャット

ボイスチャンネルへの参加・退出を操作します。

/vc join channel:チャンネル
指定したボイスチャンネルにミアを参加させます。
/vc leave
参加中のボイスチャンネルからミアを退出させます。

ミニゲーム ・ 遊び パズル・おみくじ

/play ミニゲーム

テンパズル(Make 10)やおみくじなどのミニゲームで遊べます。

/play ten-puzzle generate [answer-gen:答え同時生成] [hide:真偽値]
4つの数字を四則演算(+ - × ÷)のみで10にする式を考えるパズルをランダム生成します。
/play ten-puzzle answer q:問題の数字 [hide:真偽値]
テンパズルの解答を出力します。
/play omikuji [hide:真偽値]
日替わりのおみくじをロールします。
猫化機能 (nekoka) 常時機能

チャットメッセージの語尾を猫語に変換する遊び心満載のギミックです。

プライバシー ・ その他 統計・招待

/statistics 個人統計データ

送信文字数やメッセージ数など、ミアが収集した統計データの確認・完全削除が可能です。

/statistics get [hide:真偽値]
自分の統計情報(メッセージ送信数、文字数等)を取得します。
/statistics clear
ミアが保持しているあなたのデータを完全にリセット・消去します。
/invite Bot招待リンク

ミアを別のサーバーに招待するための認証URLを発行します。

/invite [hide:真偽値]
ミアの公式招待リンクを発行してチャットに表示します。
